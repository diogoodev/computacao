## 🎯 Objetivos da Disciplina

- [ ] Estudar e praticar processos relacionados a produção de software;
- [ ] Compreender os modelos de processos de software iterativo incremental;
- [ ] Levantar, analisar e documentar requisitos de software;
- [ ] Compreender os fundamentos sobre a linguagem de modelagem UML;
- [ ] Elaborar modelagem de software orientado a objetos com os Diagramas de Classes e Caso de Uso.
